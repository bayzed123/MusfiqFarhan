Publishing guide
  1. Use one clear, truthful title that matches the page.
  2. Add a unique SEO title and meta description; do not paste keyword lists.
  3. Choose a category, add a descriptive image and alt text, then set the canonical URL.
  4. Only publish after the preview fields are complete. Drafts can be saved with incomplete SEO.
