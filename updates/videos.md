# Video Gallery

Add your videos here using YouTube, Instagram, or Facebook links. Videos will automatically embed!

## YouTube Videos

Format:
```
Title: Video Title
Caption: Your caption here
[Watch on YouTube](https://www.youtube.com/watch?v=VIDEO_ID)
```

Example:
```
Title: Tipu Sultan - Official Trailer
Caption: Watch the thrilling trailer of my latest drama series
[Watch Trailer](https://www.youtube.com/watch?v=dQw4w9WgXcQ)
```

## Instagram Videos

Format:
```
Title: Instagram Post
Caption: Your caption here
[View on Instagram](https://www.instagram.com/p/POST_ID/)
```

## Facebook Videos

Format:
```
Title: Facebook Video
Caption: Your caption here
[Watch on Facebook](https://www.facebook.com/VIDEO_URL)
```

## How to Add Videos

### YouTube:
1. Find your video on YouTube
2. Copy the URL from the address bar
3. Add to this file using the format above

### Instagram:
1. Go to your Instagram post
2. Copy the URL from the address bar
3. The URL should look like: `https://www.instagram.com/p/ABC123XYZ/`
4. Add to this file

### Facebook:
1. Find the video on Facebook
2. Copy the video URL
3. Add to this file
