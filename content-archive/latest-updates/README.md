# Latest Updates Folder

## 📢 How to Add Updates

### Simple Steps:

1. **Create a new file** in this folder
2. **Name format:** `YYYY-MM-DD-update-name.md`
   - Example: `2026-05-14-new-project.md`

3. **Copy this template** and fill in your update:

```markdown
---
title: Update Title
date: 2026-05-14
type: Announcement
priority: High
image: https://drive.google.com/uc?export=view&id=FILE_ID
---

# Update Title

Your update content here. Keep it concise and impactful.

## Key Points:
- Point 1
- Point 2
- Point 3

---

**Status:** Active
**Read More:** [Link to more info]
```

### File Naming:
- **Good:** `2026-05-14-new-drama-announcement.md`
- **Good:** `2026-05-15-award-nomination.md`
- **Bad:** `update.md`
- **Bad:** `my update.md`

### Template Fields:

| Field | Required | Example |
|-------|----------|---------|
| title | Yes | "New Drama Project Announced" |
| date | Yes | 2026-05-14 |
| type | Yes | Announcement, Achievement, Project, News |
| priority | Optional | High, Medium, Low |
| image | Optional | Google Drive link |

### Update Types:

| Type | Example | When to Use |
|------|---------|------------|
| **Announcement** | "New Project Announced" | New projects, collaborations |
| **Achievement** | "Won Best Actor Award" | Awards, nominations, milestones |
| **Project** | "Drama Release Date" | Project launches, releases |
| **News** | "Featured in Magazine" | Media coverage, news |

### Multiple Updates in One File:

You can add multiple updates in a single file:

```markdown
---
title: May Updates - Multiple Announcements
date: 2026-05-14
---

## Update 1 - New Project
Content here...

## Update 2 - Award Nomination
Content here...

## Update 3 - Event Appearance
Content here...
```

### Push to GitHub:

```bash
# Add your new update file
git add latest-updates/2026-05-14-new-project.md

# Commit with a message
git commit -m "Add update: New Project Announcement"

# Push to GitHub
git push origin main
```

✅ **Your update will automatically appear on the Latest Updates section!**

## 📋 Update Guidelines:

- **Concise:** Keep updates brief and impactful
- **Clear:** Use clear headings and bullet points
- **Current:** Use today's date
- **Professional:** Maintain professional tone
- **Relevant:** Only share important updates

---

## 🎯 Best Practices:

1. **One Update Per File:** Create separate files for different updates
2. **Use Dates:** Always include current date
3. **Add Images:** Include relevant images when possible
4. **Be Specific:** Provide details and links
5. **Professional Tone:** Keep it professional and engaging
