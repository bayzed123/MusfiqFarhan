# Musfiq R. Farhan Official Portfolio - Technical Wiki

This Wiki provides an in-depth look into the technical architecture, implementation details, and customization guidelines for the Musfiq R. Farhan Official Portfolio website. It is designed for developers and maintainers who wish to understand, modify, or extend the project.

## 1. Core Technologies

The website is built using a modern frontend stack focused on performance, responsiveness, and maintainability:

*   **HTML5**: Semantic markup for clear structure and SEO.
*   **CSS3**: Advanced styling, animations, and responsive design using CSS variables for theme management.
*   **Vanilla JavaScript**: All interactive elements, DOM manipulation, and API integrations are handled without external frameworks, ensuring a lightweight and high-performance application.
*   **Google Firebase Realtime Database**: Utilized for the Live Fan Wall to provide real-time, globally synchronized message persistence.
*   **Font Awesome**: For scalable vector icons.
*   **Google Fonts**: `Playfair Display` (serif, for luxury titles), `Inter` (sans-serif, for body text), and `Cinzel` (serif, for cinematic accents).
